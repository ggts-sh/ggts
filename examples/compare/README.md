# Svelte vs React comparison (local)

Side-by-side live hosts for nine basic React examples:

- `col/basic`
- `histogram/basic`
- `point/scatter-color`
- `hline/threshold`
- `bar/horizontal`
- `jitter/basic`
- `area/basic`
- `vline/cutoff`
- `freqpoly/basic`

Start from the repo root:

```sh
bun run examples:compare
```

Or from `examples/`:

```sh
bun run compare
```

Open <http://127.0.0.1:4177/>
