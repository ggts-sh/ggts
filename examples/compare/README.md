# Svelte vs React comparison (local)

Side-by-side live hosts for the three basic React spike examples:

- `col/basic`
- `histogram/basic`
- `point/scatter-color`

Start from the repo root:

```sh
bun run examples:compare
```

Or from `examples/`:

```sh
bun run compare
```

Open <http://127.0.0.1:4177/>
